# Small Tools TG Bots collection

Minibots are tools for simple tasks. 
They're grouped by effect they make.

Groups of use:

#### Visual

All about colors in first place, expanding to overral sensual sphere.

#### Action

Tools to contact with Owner or something, using programm abilities.

#### Logic

Dealing with numbers, codes, calculations and further abstracts.

--

Relying idea is to give very simple intuitive instrument for all aspects, as well as it can have seamless symbiose with Owner and Owner's area.

## Basic simple mini's

#### Visual / Picker
Core: colorpicker with advanced design modes
Additional: smart control for lights

#### Action / Time
Core: timer with semantic control and Owner communication
Additional: buddy for handling comfortable work flow and ambient activity

#### Action / Scan
Core: bar/QR reader and generator
Additional: personal crawler and ad-hunter

#### Logic / Calculate
Core: calculator as graphic interface and as text prompt
Additional: task tracker and planner

#### Logic / Random
Core: random generator for all needs 
Additional: dice / coin / whatever
